## 構成案

1. Jev とは(System One Model という新しい種類 → カーネマンの System 1 / 2 が由来、70〜500ms、料金は Haiku の1/24・Opus の1/119)
2. API の形(state + 型付き質問 → 確率付きの答え)と、質問の型3つの代表例
3. デモ1: **ターンバトル**
   - かんたん × リアルタイム: 速さの差がそのまま勝敗に出る(Jev の勝ち)
   - むずかしい × ターン制: 予告もヒントもないと Jev は崩れ、Opus が考えて勝つ
4. デモ2: **一次仕分け** — 問い合わせ30件を Jev が受け、迷った分だけ Opus に上げる(対応の階層)
5. 分かったこと
   - 遅いと判断が古くなる(速さは正しさにも効く)
   - state の書き方と指示の一言で判断が大きく変わる
   - 計算はコード側で済ませる
6. 使い分けではなく「対応の階層」(層0 コード → 層1 Jev → 層2 LLM)、できないこと
7. 触ってみて(Cloudflare に上げてある。合言葉を入れなければダミーの動き)
8. Appendix: 模擬面接(Claude が質問、Jev が採点)

技術スタック(Hono + Workers、AWS との比較)は発表では触れない。聞かれたら docs/design.md の内容で答える。

## 計測結果

### Playground(3択の質問、ローカルから、同時に5回)

| 回 | 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|---|
| Jev | 581ms | 324ms | 267ms | 243ms | 360ms |
| Claude Haiku 4.5 | 1246ms | 882ms | 839ms | 846ms | 771ms |

温まった後の Jev は約 240〜360ms で、Haiku(一番軽い Claude)のおよそ3倍速い。Opus と比べる数字はまだ取っていない。

### ターンバトル

| モード | Jev | Claude Haiku 4.5 |
|---|---|---|
| リアルタイム(敵 1000ms) | 2.5秒・8回で勝利(平均 294ms) | 5回動く間に負け(平均 1016ms) |
| ターン制(6戦) | 4勝(平均 282ms) | 3勝(平均 929ms) |

リアルタイムの Claude は、考えている間に状況が変わって判断がずれた(敵が力をためている間に防御し、防御が切れたところで痛恨の一撃を受けた)。

### 一次仕分け(問い合わせ30件・しきい値 0.6・実測)

| | 件数 | 時間 | 料金 |
|---|---|---|---|
| 層1: Jev | 30件(平均 253ms) | 1.5秒 | $0.0007 |
| 層2: Opus 5(low) | 3件(10%) | 6.1秒 | $0.016 |
| 参考: 全件 Opus | 30件 | 26.1秒 | $0.153 |

階層にすると時間は約3分の1、料金は約10分の1。Opus は Jev が迷った1件を「請求 → 配送」に直した。

### 問い合わせフォーム(おまけ。「途中で話が変わる」を自動入力)

| 時点 | Jev | Claude Haiku 4.5 |
|---|---|---|
| 入力開始から約1.8秒 | 7文字遅れ | 26文字遅れ |
| 入力完了後 | 判定11回・平均 286ms | 判定4回・平均 999ms |

### ターンバトル「かんたん」(リアルタイム・敵 1000ms・3列同時)

| | 結果 | 行動回数 | 平均判断時間 |
|---|---|---|---|
| Jev | 2.5秒で勝利 | 8回 | 293ms |
| Claude Haiku 4.5 | 6.6秒で勝利 | 7回 | 927ms |
| Claude Opus 5(effort low) | 8.0秒で敗北 | 2回 | 2,357ms |

### ターンバトル「むずかしい」(ターン制・4戦)

| | 勝敗 | 平均判断時間 |
|---|---|---|
| Jev | 0勝4敗(敵 HP 約190残り) | 約 310ms |
| Claude Haiku 4.5 | 0勝4敗(敵 HP 3〜44 残りの惜敗) | 約 1.0秒 |
| Claude Opus 5(effort medium) | 4勝0敗 | 約 5.7秒 |

3段階に分かれる: Jev はヒントがないと崩れる / Haiku は攻められるが先を読めずあと一歩 / Opus は計画的に立ち回って勝つ。
「かんたん: Jev > Haiku(速さ)」「むずかしい: Opus > Haiku > Jev(考える力)」で、速さと考える力のトレードオフを見せられる。

詳細は [battle.md](battle.md#むずかしいの検証)。

### 気づき(スライド候補)

- Jev の確信度は質問の書き方で大きく変わる。5択の行動選択で確信度 6%、確率がほぼ横並びになったことがある
- 一方、`score`(ピンチ度)は 74% とはっきり出た

## ライブデモの注意

- ターン制は1戦 20〜30 秒かかるので、ライブはリアルタイムを主役にする
- むずかしい × Opus は1戦 1〜2 分かかる。ライブでは途中から話を進めるか、事前に録画しておく
- 画面が狭いと3列が縦に並ぶ。横に並べるには幅 1024px 以上(1440px 程度あると見やすい)
- むずかしいの Opus 待ちが長いときは、先に Jev・Haiku だけ動かして結果を見せ、Opus は別に動かす(前回の結果が残る)
- 初回の呼び出しは遅い(Jev で約 600ms)。本番前に一度 Playground を叩いて温めておく
