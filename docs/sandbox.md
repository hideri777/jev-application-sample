# ダミーモード仕様

勉強会の参加者が GitHub からクローンして、**API キーも合言葉もなしで**手元で動きを確かめられるようにするモード。
API を一切呼ばず、検証で実際に見えた挙動を再現した「事前に決めた動き」と「本物に近い応答時間」で動く。

コードは [src/sandbox/](../src/sandbox/)。

## 切り替え

- ヘッダーの「ダミーモード」で切り替える(選んだ状態はブラウザに保存)
- サーバーの `GET /api/status` がキーと合言葉の有無を返す。次のどちらかならダミーモードに**固定**する
  - **Jev か Claude のキーが片方でも無い**(クローンしただけの環境を想定)
  - **合言葉が必要な環境で、合言葉が未入力**(公開 URL を触った人が、そのままデモを試せるようにするため)
- ダミーモード中は合言葉の欄を隠す(API を呼ばないので不要)
- バトルの各列の条件表示には「ダミー」と出る。本物の結果とダミーの結果を並べたときに区別できる

## 応答時間([latency.ts](../src/sandbox/latency.ts))

| エンジン | 待つ時間 |
|---|---|
| Jev | 240〜360ms |
| Claude Haiku 4.5 | 800〜1,100ms |
| Claude Opus 5(effort low) | 1,800〜2,800ms |
| Claude Opus 5(effort medium) | 4,500〜7,500ms |
| Claude Opus 5(effort high) | 8,000〜12,000ms |

Jev の確率・確信度は見た目のために適当に振っている(値に意味はない)。Claude は本物と同じく確率を返さない。

## バトルの判断([battle.ts](../src/sandbox/battle.ts))

[battle.md](battle.md) の検証で見えた挙動を再現する。

| | かんたん | むずかしい |
|---|---|---|
| Jev | 予告を見て素直に動く(痛恨の前に防御、倒れそうなら回復、それ以外は攻撃) | 最初に1回攻撃し、あとは防御し続ける |
| Haiku | 攻め中心。HP 30 以下で回復 | 大きな攻撃を受けた「後」に防御する(タイミングがずれる)。回復は HP 20 以下だけ |
| Opus | Jev と同じ(予告を見て動く) | 6手先まで読む。周期が分かるまで(履歴5手未満)は痛恨を想定して慎重に、分かったら周期どおりに予測。乱数の出目は見ず、ダメージの平均で見積もる |

単純なルールでは検証の Opus(4戦全勝)を再現できなかったので、Opus だけ先読みにした。

### ルールベースで確かめた勝率

| | かんたん × リアルタイム(敵 1000ms) | むずかしい × ターン制 |
|---|---|---|
| Jev | 100% | 0%(敵 HP 約190残りの大敗) |
| Haiku | 93% | 0.4%(敵 HP 約20残りの惜敗) |
| Opus | 0%(遅くて負ける) | 93% |

リアルタイムは「敵1回あたりに動ける回数」を Jev 3.3 / Haiku 1.05 / Opus(low)0.43 として計算した。

## 問い合わせフォームの判定([form.ts](../src/sandbox/form.ts))

キーワードで判定する。

- 担当部署: 請求・支払い / アカウント / 技術サポート / 配送 のキーワードのうち、**文中で最後に出てきたもの**(話が途中で変わったら切り替わる)。「解決」がそれより後にあれば「その他」
- 緊急度: 「至急」「明日まで」などで最高、「できません」「届きません」などで高め
- 返金の依頼: 「返金」「返品」「二重」
- 怒っている: 「解約」「至急」「!」など

## 模擬面接([interview.ts](../src/sandbox/interview.ts))

質問は用意した一覧から出し、Jev の採点はキーワード(あいまい語・つなぎ言葉・数字や具体例)、講評は2種類のひな形。詳しくは [interview.md](interview.md)。

## Playground([generic.ts](../src/sandbox/generic.ts))

自由に書かれた質問は理解できないので、選択肢の説明と state の文字の重なりで答えを選ぶだけ。画面にもその旨を出している。
